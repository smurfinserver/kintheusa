# 공식 여권 서식 출처

원본 출처: [외교부 여권안내 신청서식 모음](https://www.passport.go.kr/home/kor/applicationForm/index.do?menuPos=42)

2026-10-21 공식 문서 뷰어의 PDF 다운로드 기능을 통해 수집했다. 원본 PDF 14개는 수정하지 않았으며, 파일별 원본 이름·공식 파일 키·페이지 수·SHA-256은 `assets/form-catalog.js`에 기록했다. `npm run check`와 Playwright 다운로드 테스트가 무결성을 검사한다. HWP는 복제하지 않았으며 공식 페이지에서 확인할 수 있다.

## 포함 범위

- 기존 두 종류: 여권 발급 신청서, 법정대리인 동의서의 공식 원본. 기존 사용자 제공 판본의 자동 입력 편집기는 그대로 보존한다.
- 추가 11종: 공동친권자 부동의서, 부동의 의사 철회서, 보호자 동의서, 위임장, 로마자성명 변경 신청서, 기재사항변경 신청서, 분실 신고서, 실효확인 신청서, 비자 노트 신청서, 사실증명 신청서, 긴급여권 발급신청 사유서.
- 작성예시 1종: 다운로드 전용. 예시의 기입 내용은 공식 원문에 포함된 참고 내용이며 사용자가 작성한 결과물이 아니다.

## 편집 방식과 출력

새 모음의 빈 서식 13종은 사용자가 원본에서 위치를 선택하는 공통 편집기를 사용한다. 이름·날짜 등의 위치를 자동 추정하거나 법적 요건을 판정하지 않는다. 텍스트·체크 표시, 위치/크기 조절, 삭제/undo, JSON 내보내기/가져오기, PDF 저장/인쇄를 제공한다. **입력 항목당 500자, 서식당 200항목**까지다.

작성본은 A4 이미지 기반 PDF이며 텍스트 검색이나 전자서명 기능이 없다. 원본 미리보기 PNG는 Poppler로 생성했다(긴 변 1,684px). `node scripts/render-form-pages.cjs`로 재생성할 수 있으며 일반 빌드에는 Poppler가 필요 없다.

공식 페이지는 컬러·100% 비율 출력과 신청서/동의서 수기 작성을 안내한다. 화면에 이 안내와 공식 출처를 표시하며, 웹 작성본은 내용 정리·작성 연습에 사용하고 제출 방식은 접수기관 안내를 따르도록 설명한다. 서명은 수기로 작성해야 한다.

원본은 수집 시점의 사본이다. 공식 서식이 바뀌면 파일 키/해시/페이지 이미지와 테스트를 함께 갱신해야 한다. 기존 편집기의 날짜 좌표를 새 판본에 그대로 재사용하지 않는다.
