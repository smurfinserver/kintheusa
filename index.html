# Codex 작업 규칙 — KIN THE USA 이 저장소는 미국 거주 한국인을 위한 16개 브라우저 도구의 정적 웹사이트입니다. ## 시작 전 반드시 확인 - `CODEX_TASK.md`를 읽고, `docs/QA_MATRIX.md`, `docs/PWA_ARCHITECTURE.md`를 참고하십시오. - 먼저 저장소 파일과 현재 동작을 확인하고, 증거 없이 "검증됨" 또는 "배포 완료"라고 말하지 마십시오. - 실 서비스 배포는 사용자가 접근을 허용한 GitHub 저장소/호스팅 계정에서만 시행하십시오. 도메인 DNS나 비용 발생 서비스 설정은 별도 동의를 받으십시오. ## 변경 원칙 - 기존 카드형 디자인 및 한국어 UI를 최대한 유지하고, 각 기능의 기존 동작을 회귀 테스트하십시오. - 정적 HTML/CSS/JS 구성을 유지하십시오. 새 프레임워크, DB, 로그인, API 서버는 명시적 근거가 없으면 추가하지 마십시오. - 모든 사용자 사진, PDF, 이름, 주소, 주민등록번호는 브라우저 내부에서 처리하십시오. 로그, 분석 도구, 네트워크 요청 또는 원격 서비스로 전송하지 마십시오. - 서비스 워커/Cache Storage에 사용자 입력값, 생성된 PDF/이미지, 오브젝트 URL 등을 저장하지 마십시오. - 배포 경로가 `/`이든 `/repo/`이든 링크가 작동하게 상대 경로를 유지하십시오. - 테스트는 자동화할 수 있는 부분은 Playwright로 작성하고, 다운로드된 파일을 실제로 읽어서 결과를 검증하십시오. - 테스트 실패나 미검증 항목을 숨기지 않고 `docs/QA_REPORT.md`에 기록하십시오. - 테스트용 데이터는 완전히 가상의 값만 사용하십시오. 개인정보가 담긴 결과물을 저장소에 커밋하지 마십시오. - 로컬 환경에서 HTTP로 실행하여 검증하십시오. `file://` 직접 실행만으로 PWA 또는 클립보드 기능을 검증하지 마십시오. ## 작업 완료 기준 1. 전체 16개 카드에서 동작/다운로드/이동을 확인함. 2. 배포 주소가 실제로 열리고 필요한 정적 리소스를 제공함(권한 없으면 배포 절차와 차단 요인 명시). 3. PWA 전환 가능 구조와 관련 문서가 준비됨. PWA 설치/오프라인 동작을 구현했다면 각각 실제 테스트로 입증함. 4. 변경 목록, 실행한 테스트/결과, 미해결 사항, 배포 URL을 최종 보고함.
